# 새 직업·새 장소 추가 가이드

광장 남쪽 "생활 거리"의 건물과 장소 안 지도는 **데이터(`src/places-data.js`)** 에서 자동으로 만들어져요.
그리는 코드(`src/places-engine.js`)는 보통 건드리지 않아요. 건물 배치, 지도 높이, 알림 설정 칩, 오늘 화면 요약, 광장 입장 카드는 모두 데이터를 읽어서 늘어나요.

## A. 새 직업만 생겼을 때 (기존 장소를 쓰는 경우)
1. `src/data2.js` 의 `META` 에 직업 이름·분류·설명을 추가해요.
2. `src/template.html` 의 `J` 목록(직업 색, 머리 장식, 도구, 역량, 퀘스트)과 `HABITS`(직업별 습관)에 항목을 추가해요.
3. `src/places-data.js` 에서 그 직업이 일하는 장소의 `jobs` 배열에 직업 id 를 넣어요. 직업은 한 장소에만 넣어요.
4. 빌드하고 점검해요(아래 "빌드와 점검").

## B. 새 장소를 만들 때 (예: 도서관, 은행, 공장)
1. `src/places-data.js` 의 `PLACE_DEFS` 맨 **뒤**에 항목을 하나 추가해요.
   ```js
   library:{n:'도서관',sub:'지식',jobs:['librarian'],
     st:{m:'열람실',n:'카페',e:'서고'},                 // 아침/점심/저녁 구역 이름
     look:{body:'#D9C7A3',roof:'#8B6A47'},               // 건물 색(선택)
     scene:{wall:'#E9DCC4',floor:'#F1E7D3',blocks:[['#B58B5A','#8B6A47'],['#C9A06A','#9C7840'],['#8B6A47','#5A4630']]}, // 지도 색(선택)
     hb:{m:[[제목,최소 버전,역량] x3], n:[...x3], e:[...x3]}}
   ```
   - 구역마다 습관은 **정확히 3개**예요. 역량은 `creativity, problemSolving, collaboration, leadership, empathy, analytical, execution, challenge` 중 하나예요(앱의 `STATS` 와 같아야 해요).
   - 건강 효과를 단정하는 문구는 쓰지 않아요. 아주 작은 행동과 "최소 버전"으로 적어요.
2. 건물은 5채씩 한 줄로 가운데 정렬돼요. 6번째부터는 다음 줄이 생기고 광장 지도가 자동으로 길어져요.
3. 그림을 따로 만들고 싶으면 `src/places-engine.js` 에 같은 id 로 등록해요. 등록하지 않으면 색으로 자동으로 그려져요.
   - 건물: `BLD.library=(g,x,h)=>{const{R,E,T}=h; ...}` (x 는 건물 가운데, 세로 좌표는 첫 줄 기준이에요)
   - 장소 안: `SCN.library=(h)=>{const{g,R,E,T,grid,B}=h; ...}` (`B('m',채움,테두리)` 로 구역 가구를 그려요. 구역 위치는 `PST` 에 고정돼 있어요)
4. 직업은 위 A 와 같이 `jobs` 에 연결해요. 직업이 아직 없는 장소(`jobs:[]`)도 만들 수 있어요.

## 지켜야 할 규칙 (저장 기록과 연결돼요)
- **장소 id 와 습관 순서는 한 번 정하면 바꾸지 않아요.** 완료 기록(`장소.구역번호`)과 알림 설정이 이 id 에 묶여 있어요.
- 장소를 없앨 때는 목록에서 빼기만 해요. 남은 기록은 무시돼요. 같은 id 를 다른 장소에 다시 쓰지 않아요.
- 장소 순서를 바꾸면 건물 위치만 바뀌고 기록은 그대로예요. 그래도 사용자가 위치에 익숙하니 새 장소는 뒤에 추가해요.
- 장소가 늘면 하루 경험치 상한(`PL_MAX`, 지금 6개)과 장소당 습관 수(`PL_PER`, 9개)를 같이 점검해요.
- 광장에서 한 줄에 5채가 넘으면 줄이 늘어요. 한 줄 개수는 `PL_COLS` 로 바꿔요(건물 너비 때문에 5 가 적당해요).

## 빌드와 점검
```bash
cd src
python3 build_all.py                      # out/ 에 배포 파일 3종 + 루트 index.html 생성 (esbuild 필요)
node ../tests/places_check.js out/career-quest-party.html   # 데이터 형식, 모든 직업의 일터, 모든 장소 지도 동작
```
`places_check.js` 가 실패하는 대표적인 경우: 습관이 3개가 아님, 없는 역량 이름, 없는 직업 id, 두 장소에 같은 직업, 일터가 없는 직업(새 직업을 넣고 `jobs` 연결을 빼먹은 경우).
