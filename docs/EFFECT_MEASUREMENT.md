# 효과 측정 설계 (v0.9.0)

목적: "직업 경험을 습관화하고, 습관을 직업역량으로 연결한다"는 가설이 실제로 일어나는지 숫자로 확인한다.
정식 심리검사가 아니라 **자기평가 + 행동 기록**이다. 사업계획서·발표에서 "측정 방법을 갖고 있다"를 보여주는 용도.

## 1. 성향 진단 (시작 시, 약 1분, 선택)
- 1단계 끌리는 활동 3개(8개 중): 창의력·문제해결·협업·리더십·공감·분석력·실행력·도전성과 1:1.
- 2단계 자기평가 8문항(1~5점): "지난 2주 동안 나는 …" 문항이 역량과 1:1. 건너뛸 수 있음.
- 3단계 추천: 직업의 핵심 역량(dna)과 고른 활동이 겹치는 정도가 높은 직업 3개(동점이면 목록 순서). 참고용이며 정식 검사가 아님을 화면에 표시.
- 문항은 `src/diag-data.js`(DIAG_ACT, DIAG_SELF)에서 고친다.

## 2. 자기평가 변화 (사전·사후)
- 처음 한 평가 = `pre`(기준). 14일 뒤 오늘 탭에 안내가 뜨고, 다시 한 평가 = `chk`.
- 지표: 평균 점수(8문항 평균), 문항별 변화, 평균 변화량(chk − pre). 나 → 캐릭터 → "내 변화 · 참여 요약"에서 확인.
- 기준 점수가 없는 기존 사용자도 "기준 점수 기록하기"로 시작 가능.

## 3. 행동 지표 (기기에서 자동 계산)
| 지표 | 정의 |
|---|---|
| 활동일 | 퀘스트·습관을 한 번이라도 완료한 날의 수 |
| 7일 지속 | 활동일 ≥ 3 이고, 첫 활동일과 마지막 활동일의 간격 ≥ 6일 |
| 시도한 직업 수 | 습관을 1번 이상 한 직업의 수 |
| 간접/직접 경험 횟수 | 습관 완료 횟수를 단계 종류(Lv1~4 간접, Lv5~7 직접)로 합산 |
| 달성한 습관 수 | 같은 습관 7번 이상 완료 |
| 느낌 | 😄 재밌어요 / 🙂 보통 / 😕 안 맞아요 횟수, "계속 해보고 싶어요"를 누른 행동 수 |

## 4. 운영자 집계
- 온라인 버전에서 사용자가 "테스트 정보 보내기"를 켠 경우에만 위 지표의 요약값(활동일, 시도한 직업 수, 직접 경험 수, 달성 수, 7일 지속 여부, 자기평가 평균×10)이 전송된다. 한 줄 기록·한 문장 같은 글 내용은 보내지 않는다.
- 관리자 화면(테스트 현황) 맨 위에 "효과 지표 요약": 7일 이상 이어간 사람 비율, 평균 활동일, 평균 시도 직업 수, 직접 경험·달성 합계, 자기평가 평균 변화(비교 가능 인원 포함).
- 한계: 서버(Supabase)로는 아직 실제 검증을 못 했고, 표본이 작으면 통계적 의미가 없다. 비교군이 없어 "효과"가 아니라 "변화"로 표현해야 한다.

## 5. 사업계획서에 쓸 수 있는 목표 예시 (실제 수치는 시범 운영 후 채움)
- 7일 지속률 N%, 평균 시도 직업 N개, 직접 경험 1회 이상 달성 비율 N%
- 자기평가 평균 변화 +N점, "계속 해보고 싶은 행동"을 1개 이상 찾은 비율 N%
